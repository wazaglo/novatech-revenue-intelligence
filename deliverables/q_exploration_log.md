## Reflection

- **Where Q matched:** channels (Q1), resolution times (Q3), top-10 accounts (Q4), campaign losses (Q5). Q's channel math matched the CSV to the decimal, and it got the risky-account list that needs the joined model.
- **Where Q got it wrong:** average deal size (Q2). Q worked off the joined table where each deal repeats (63,420 rows vs 499 deals), so the per-tier averages ran low. Sales visuals use the 499-row CRM set to avoid that. Glossary warnings helped but didn't fix it - no wording fixes a grain mismatch, the model has to.
- **When I use which:** Q when I'm poking at a new question, especially across datasets. Dashboard when the number has to be right (win rate 63.1%, revenue $707,201). My rule: *if I'll quote it, it comes off the dashboard. If it's new, I ask Q, then check it against the dashboard.*
